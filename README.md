# Sistema de Gestión de Empleados

Sistema completo para la gestión de empleados con backend API y frontend.

## 🏗️ Estructura del Proyecto

- `backend/` - API REST con Node.js, Express y SQLite
- `frontend/` - Aplicación frontend (por implementar)

## 🚀 Características del Backend

- ✅ API RESTful para gestión de empleados
- ✅ Base de datos SQLite
- ✅ CRUD completo de empleados
- ✅ Gestión de departamentos
- ✅ Estadísticas y reportes
- ✅ Validación de datos
- ✅ Manejo de errores
- ✅ CORS habilitado

## 📋 Requisitos

- Node.js 16+
- npm o yarn

## 🔧 Instalación y Uso

### Backend

```bash
cd backend
npm install
npm run init-db
npm run dev
